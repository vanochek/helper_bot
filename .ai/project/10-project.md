# Проект и границы

Источник требований — Testovoe_zadanie_golosovoj.pdf. Архитектурный замысел —
voice_assistant_architecture.md; фактические решения и уточнения — docs/DECISIONS.md.
Модульный монолит FastAPI, PostgreSQL, нативный браузерный JS без сборщика.
Будущие слои: HTTP → прикладные сервисы → предметная модель → адаптеры БД и AI.
LLM не выполняет SQL и не подтверждает несохранённые операции. Данные пользователей изолированы.
Даты хранить с часовым поясом, относительные даты вычислять относительно пользователя.
Не логировать речь, личные записи, ключи. Изменения схемы — только Alembic.
Не добавлять микросервисы, брокеры или CI/CD без отдельной потребности.

Команды: python dev.py bootstrap, check, smoke, serve, sync-agents, doctor,
backup, restore-check [файл], restore-new [файл] (допускают --production),
deploy-init, deploy-up. Эксплуатация — docs/OPERATIONS.md, публикация — docs/DEPLOYMENT.md.
Зависимости фиксируются uv.lock, обновляются осознанно с проверками.
Тесты домена должны работать без платного API. Проверки не ослаблять ради успешного результата.
После изменения поведения обновлять README, STATE, ROADMAP и решения по необходимости.
