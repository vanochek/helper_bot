# Голосовой помощник

Прототип управления задачами, напоминаниями и встречами через речь и текст.
Готовы хранение, API и текстовый интерфейс с AI-адаптером. Добавлены голосовой ввод и браузерное озвучивание.
По умолчанию включён локальный имитатор AI_MODE=demo: ключи не нужны.

## Запуск в Windows

Нужны Python 3.14, Git и запущенный Docker Desktop с Linux containers.

```powershell
python -m pip install uv
python dev.py bootstrap
python dev.py check
python dev.py smoke
python dev.py serve
```

Открыть http://127.0.0.1:8000; API: /docs, проверки: /health/live и /health/ready.
Bootstrap создаёт .env с локальным случайным паролем, окружение из uv.lock и запускает PostgreSQL.
Повторный запуск сохраняет .env и данные. Остановка БД: `docker compose stop`.
Не удаляйте volume: он хранит данные. Порт 55432 должен быть свободен.
Ключ OpenAI нужен только для AI_MODE=openai; деморежим работает автономно.

## Хранение и проверки

`python dev.py bootstrap` применяет миграции. Полный `check` требует PostgreSQL:
интеграционные тесты работают в отдельных временных схемах и очищают их после выполнения.
Модель содержит анонимные сессии и записи; доступ к записям ограничивается владельцем
в репозитории и HTTP API. Подключены браузерные cookie и проверка Origin. Очистка cookie
означает потерю доступа к анонимным данным — восстановления аккаунта в MVP нет.

## Обновлённый интерфейс
Тёмная тема включена по умолчанию, светлая переключается в шапке и сохраняется в браузере.
Быстрые команды заполняют поле для проверки перед отправкой. Ctrl+Enter отправляет сообщение.
Оболочка занимает высоту окна; длинная история прокручивается внутри области диалога.
На узких экранах боковая панель скрывается; уменьшение движения учитывается автоматически.

[Подключение Groq: ключ, запуск и проверка](docs/GROQ.md). Доступен AI_MODE=groq.

[Если Docker не загружает образы: EOF и прокси](docs/DOCKER_TROUBLESHOOTING.md).

Groq использует отдельную схему местного времени; сервер повторно проверяет ответ перед сохранением.

После подтверждённого отказа AI можно повторить запрос или нажать «Изменить сообщение».
При неизвестном результате остаётся повтор с тем же идентификатором.
