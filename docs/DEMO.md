# Локальный запуск без API-ключей

Для уже подготовленного компьютера запустите Docker Desktop, затем:

```powershell
python dev.py ai-mode demo --production
python dev.py deploy-up
```

Откройте http://localhost:18080. Для новой установки сначала выполните
`python dev.py deploy-init`. Новая конфигурация использует HTTP localhost и порты
18080/18443, привязанные к 127.0.0.1. Существующая конфигурация не перезаписывается:
для локального HTTP задайте DOMAIN=http://localhost и APP_ORIGIN=http://localhost:18080.
Браузер допускает микрофон на localhost после разрешения пользователя.

## Что проверить

- «Создай задачу купить молоко завтра» — запись с датой без времени.
- «Напомни завтра позвонить Ивану» — уточнение; ответьте «в 10:00».
- «Создай встречу с Анной завтра в 15:00» — встреча с точным временем.
- «Покажи планы на завтра» — реальные сохранённые записи за день.
- «Найди задачу про молоко» — поиск в PostgreSQL.
- «Отмена» — сброс текущего уточнения.

Поддерживаются сегодня, завтра, послезавтра и дата ГГГГ-ММ-ДД, время в ЧЧ:ММ
или «в 10». При запросе в прошлом сервер попросит подтверждение «да».
Имитатор предназначен для этих шаблонов, произвольную речь он не понимает.
После неподдерживаемой команды отмените уточнение и введите команду из примеров.
Напоминания здесь — записи; отправка уведомлений в установленное время не реализована.

Голосовая заглушка принимает запись, но не анализирует её: всегда возвращает
«Напомни завтра в 10:00 позвонить Ивану». Интерфейс явно сообщает об имитации;
проверьте или исправьте текст перед отправкой. Озвучивание ответа выполняет браузер;
наличие русского голоса и его работа без сети зависят от системы.
В demo приложение не обращается к OpenAI даже при заполненном ключе.
Записи, история, изоляция браузеров, уточнения и защита от дублей работают с настоящей БД.

## Подключение настоящего AI позже

В исключённом из Git файле deploy/.env заполните OPENAI_API_KEY, OPENAI_MODEL
(Responses API со структурированными ответами) и OPENAI_STT_MODEL (Audio Transcriptions).
Затем:

```powershell
python dev.py ai-mode openai --production
python dev.py deploy-up
```

Обновите страницу: индикатор должен показывать OpenAI. Проверьте текстовый диалог
и собственную запись микрофона. Запросы тарифицирует провайдер. При ошибке ключа
приложение покажет ошибку, не будет подменять результат имитацией.
Вернуться к заглушкам: ai-mode demo --production и deploy-up. Записи сохранятся.
Для запуска через serve используйте ai-mode без --production и перезапустите сервер.
Можно также вручную изменить AI_MODE=demo/openai в соответствующем .env и перезапустить.

## Остановка и повторный запуск

```powershell
docker compose --env-file deploy/.env -f deploy/compose.yaml stop
python dev.py deploy-up
```

Не удаляйте volumes: там база. Резервная копия: `python dev.py backup --production`.
Очистка cookie лишает доступа к анонимной истории. Публичный сервер для локального
деморежима не нужен. Живая приёмка OpenAI/STT ожидает ваших ключей.

Доступен также AI_MODE=groq: подключение описано в GROQ.md.
