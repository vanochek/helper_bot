# Groq: текст и распознавание речи

Поддерживается AI_MODE=groq. Текст: GROQ_MODEL=openai/gpt-oss-120b;
речь: GROQ_STT_MODEL=whisper-large-v3-turbo. Нужен GROQ_API_KEY.
Ключ хранится только в исключённых из Git .env и deploy/.env.

## Запуск

Для локального сервера заполните три поля GROQ_* в .env:

```powershell
python dev.py ai-mode groq
python dev.py serve
```

Для Docker заполните те же поля в deploy/.env (при отсутствии сначала deploy-init):

```powershell
python dev.py ai-mode groq --production
python dev.py deploy-up
```

Адрес Docker: http://localhost:18080. Перезагрузите страницу: индикатор покажет Groq.
Настройки .env и deploy/.env независимы. Существующие данные и пароли не перезаписывайте.
Для возврата к имитатору используйте ai-mode demo с тем же флагом и перезапустите.

## Проверка

«Напомни завтра позвонить Ивану» → уточнение → «в 10:00» → одна запись.
Проверьте список на завтра и поиск, затем запись микрофона: перед отправкой текст
можно исправить. Настоящий микрофон проверяет владелец на своём устройстве.
Текст и голос передаются Groq; автоматического отката к имитатору нет.
401 означает проблему ключа, 403 — отказ доступа, 429 — ограничение квоты.
Не обходите проверки TLS; при сетевом отказе проверьте доступность api.groq.com.

Адаптер использует существующий SDK с адресом https://api.groq.com/openai/v1,
Chat Completions со строгой JSON-схемой и Audio Transcriptions (русский язык).
Ответ валидируется через Intent; разрешение времени и сохранение выполняет сервер.
Квоты и доступные модели проверяйте в консоли Groq, они могут меняться.

Документация: https://console.groq.com/docs/structured-outputs,
https://console.groq.com/docs/speech-to-text.

Для местного времени в схеме провайдера используется шаблон ЧЧ:ММ:СС вместо
format=time. Ответ дополнительно проверяется доменной моделью; смещения запрещены.
Ошибка несовпадения схемы обозначается отдельно от недоступности провайдера.

При APIConnectionError выполняется ещё одна попытка с новым клиентом; тайм-аут
каждой сетевой операции попытки — 10 секунд. HTTP-отказы не повторяются автоматически.
Краткий сетевой сбой может восстановиться, постоянный отказ сети останется ошибкой.
Повтор провайдера не сохраняет записи: commit выполняется после получения и проверки намерения.
