# Границы и приёмка первой версии

Обязательны четыре действия: создать задачу/напоминание, создать встречу,
показать записи за период, найти ранее сохранённую запись. Ввод — текст и короткая
голосовая запись; ответ — текст, озвучивание при поддержке браузера.

| Пример | Ожидаемый результат |
|---|---|
| Напомни завтра в 10 позвонить Ивану | reminder, точное время, сохранение и подтверждение |
| В пятницу отправить отчёт | task с датой без выдуманного времени |
| Купить билеты | task без срока |
| Встреча с командой завтра в 15 | meeting с точным временем |
| Встреча с Иваном завтра | Уточнение времени, до ответа запись не создаётся |
| Какие планы на сегодня? | Только записи владельца за его локальные сутки |
| Найди задачу про презентацию | Поиск по словам и словоформам, без требования точного совпадения |

Близкий по смыслу поиск оценивается на приёмочном наборе; embeddings — расширение,
если полнотекстового поиска окажется недостаточно. Записи без срока не включаются
в календарный период автоматически, но доступны в общем списке и поиске.

Время: IANA-зона пользователя, точные моменты — aware datetime / TIMESTAMPTZ,
дата без времени — DATE. Интервалы полуоткрытые [начало, конец).
Неоднозначное время при переходе DST требует уточнения; прошлое время не переносится
на будущую дату молча. Правила интерпретации относительных дат реализуются на этапе 4.

Сессия анонимная, сервер генерирует случайный токен, хранит только SHA-256.
Владелец никогда не выбирается LLM или аргументом пользовательского действия.
Зона должна быть явно получена от пользователя/браузера. Очистка cookie теряет доступ;
аккаунты, перенос между устройствами и восстановление доступа не входят в MVP.
Cookie и проверка Origin будут реализованы до открытия предметного HTTP API.

Название: 1–500 символов после strip; подробности: до 10000 символов.
Типы: task/reminder/meeting. Статусы: open/done/cancelled, создание только open.
Встреча и напоминание требуют scheduled_at. Два вида срока одновременно запрещены.
Окончание допускается только у встречи и строго позже начала.

За рамками: внешние календари, повторения, реальные push-уведомления, управление
конфликтами встреч, редактирование/удаление голосом, полноценные аккаунты.
Напоминание в MVP — сохранённая запись, а не обещание доставить уведомление.
Готовность продукта: все четыре действия работают через текст и голос, данные
переживают перезапуск, изоляция проверена, опубликованы HTTPS-прототип и README.
