# Разбор образцов

Изучены codepack_export_20261028_161530.zip и CogniBoiler_export_20261028_161558.zip.
В codepack: Rust workspace, xtask, общий набор .ai/universal и .ai/project,
генерация AGENTS.md и нативные импорты CLAUDE.md, checklist и roadmap.
В CogniBoiler: Python-оркестратор, sync_agents/render.py с бюджетом инструкций,
quality_gate с набором проверок, отдельные документы фактов, планов и инвариантов.
Перенесены единый источник правил, проверка рассинхронизации, восстановление контекста,
веточный процесс и единая точка запуска проверок. Не переносились Rust, Go, MQTT,
Kubernetes, сложный каталог скриптов и англоязычная политика: они не соответствуют этому проекту.
Вместо зеркалирования настроек разрешений разных вендоров все входные файлы генерируются
из одинаковых модулей. Это исключает ложное обещание совместимости чужих конфигураций.
