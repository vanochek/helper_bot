# Текущее состояние

Подготовлена инфраструктура разработки: Python 3.14, uv.lock, FastAPI,
PostgreSQL 18 в Docker, Alembic, Ruff, mypy, pytest и общие правила агентов.
API: /, /health/live, /health/ready, /docs. При недоступной БД readiness возвращает 503.
Предметных таблиц и миграций пока нет: Alembic подключён для следующего этапа.
Четыре действия из ТЗ, голосовой ввод, AI и пользовательская изоляция ещё не реализованы.
Следующий шаг: модель данных и миграции, затем сервисы создания/списка/поиска.

Проверки подготовки: python dev.py check и python dev.py smoke.
Проверки AI не требуют API-ключа, поскольку AI-адаптер ещё не реализован.
Рабочая ветка подготовки: codex/repository-foundation.
